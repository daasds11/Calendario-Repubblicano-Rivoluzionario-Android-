# Calendario-Repubblicano-Rivoluzionario-Android-
Applicazione APK che serve ad avere un widget sul telefono android.
In quest'app troverai:
-Data e orario aggiornata in tempo reale del calendario rivoluzionario
-Colore e immagine del widget che cambia ad ogni mese in base alle ricorrenze
-Convertitore data Rivoluzionario to Gregoriano e vice versa
-Informazioni generali su come funziona il calendario
